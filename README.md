# SALES DATA ANALYSIS

AI Academia Internship | Shubham Carpenter | October 2026

## About
This project analyzes practice retail sales data to explore sales trends, products, regions, and machine learning models.

## Tools Used
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, SciPy

## Dataset
30 rows and 7 columns, covering January to March 2026. Practice data.

## Key Findings
1. Electronics generated 79.03% of total sales. This shows sales depend heavily on one category. The business could promote Furniture and Stationery more.
2. March had the highest average monthly sales: 29,745.45, about 20.72% above the three-month average. The business could plan stock ahead of March.
3. The top products were Laptop (330,000), Monitor (162,000), and Printer (60,000). The business could monitor stock for these products.
4. The regression used only three monthly data points, so its R-squared score could not be calculated. More monthly data is needed to assess a seasonal pattern.
5. The classification model had an F1-score of 0.80 for High sales, but its test set was very small. More data is needed before relying on its predictions.

## Recommendations
1. Keep popular products such as Laptops and Monitors in stock.
2. Collect more sales data over additional months to improve trend analysis and model evaluation.

## How to Run
Install pandas, numpy, matplotlib, seaborn, scikit-learn, and scipy. Open `Sales_Analysis_Final.ipynb` in Jupyter Notebook and run all cells.
